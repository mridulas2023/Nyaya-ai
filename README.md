NyayaAI is an AI-powered legal document assistant that helps users understand complex legal agreements using OCR, PDF parsing, and Large Language Models.

---

## 🚀 Features

- 📄 OCR Text Extraction
- 📑 PDF Upload Support
- 🤖 AI Legal Analysis
- ⚠️ Risk Detection
- 💬 Chat With Document
- 📥 Downloadable PDF Reports
- ✨ AI Typing Animation
- 🎨 Modern Futuristic UI
- 🖱️ Drag & Drop Upload
